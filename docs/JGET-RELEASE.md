# ScratchJGET: Windows 1.3.2-jget.4 и Mac 1.3.2-jget.3

17 ноября 2026 года. Обновление .4 относится к Windows; для Mac сохраняется выпуск .3.

Прежнее название — J-GET Junior. Самостоятельная модификация с собственным названием и оформлением на основе [ScratchJr-Desktop](https://github.com/jfo8000/ScratchJr-Desktop). Проект не связан с официальным выпуском ScratchJr и не одобрен MIT. В сборке сохранён прежний движок Electron 1.8.2-beta.3.

## Скачать

- [Windows x64 — установщик ScratchJGET-Setup.exe](https://github.com/user116RUS/J-GET-Junior/releases/download/v1.3.2-jget.4/ScratchJGET-Setup.exe).
- [Mac Intel — архив приложения](https://github.com/user116RUS/J-GET-Junior/releases/download/v1.3.2-jget.3/ScratchJGET-1.3.2-jget.3-mac-Intel.zip). На Apple Silicon требуется Rosetta.
- [Релиз Windows .4 и контрольные суммы](https://github.com/user116RUS/J-GET-Junior/releases/tag/v1.3.2-jget.4) · [Релиз Mac .3](https://github.com/user116RUS/J-GET-Junior/releases/tag/v1.3.2-jget.3).

Приложения не подписаны сертификатом издателя. Windows или macOS могут показать предупреждение при первом запуске. Нативной сборки для Mac ARM и установщика для Windows 32-bit в этом выпуске нет.

## Установка и обновление Windows

1. Войдите под той же учётной записью Windows, в которой использовали ScratchJr. Закройте ScratchJGET, J-GET Junior и ScratchJr.
2. Для старого ScratchJr сохраните копию всей папки `ScratchJR` из «Документов». Если Classroom уже установлен, сохраните всю папку `%LOCALAPPDATA%\ScratchJr-Classroom\Projects`, включая `media`.
3. Сохраните предыдущий установщик. Запустите `ScratchJGET-Setup.exe` и пройдите мастер установки. Установка выполняется для текущего пользователя.
4. Откройте программу через ярлык «ScratchJGET» на рабочем столе или в меню «Пуск».

Если библиотека прежней Classroom-сборки ещё не создана, первый запуск ScratchJGET копирует работы из фактической папки «Документы\ScratchJR». При использовании OneDrive расположение «Документов» может отличаться. Старая база остаётся на месте. После переноса исходный ScratchJr Desktop и ScratchJGET используют отдельные библиотеки: новые работы появляются в ScratchJGET. Прежняя Classroom-сборка и ScratchJGET используют одну библиотеку; её путь сохранён для совместимости.

Если старая база не читается, версия .4 предлагает «Начать с пустой библиотекой». Исходная папка остаётся на месте, а новая библиотека создаётся отдельно. Этот выбор не восстанавливает старые проекты. Если они нужны, закройте окно и сохраните исходную папку для проверки на копии. Уже существующая рабочая библиотека не заменяется пустой. [Подробности исправления](RELEASE-NOTES-1.3.2-jget.4.md).

Установщик обновляет прежнюю Classroom-сборку или J-GET Junior в существующей папке и заменяет её ярлыки на «ScratchJGET». Повторная установка обновляет программу. Рабочая библиотека находится отдельно от файлов приложения; деинсталлятор её не удаляет.

## Установка и обновление Mac

1. Закройте ScratchJGET, J-GET Junior и прежний ScratchJr. Сохраните копию всей папки `~/Documents/ScratchJR` и предыдущего приложения.
2. Распакуйте `ScratchJGET-1.3.2-jget.3-mac-Intel.zip`.
3. Перенесите извлечённое `ScratchJGET.app` в папку «Программы». Если там уже есть ScratchJGET, замените его новой версией.
4. Запустите ScratchJGET из «Программ». Прежние приложения J-GET Junior и ScratchJr можно сохранить отдельно; не запускайте разные версии одновременно с одной библиотекой. На Mac с Apple Silicon используется Rosetta; приложение остаётся Intel x64.

Mac-версия продолжает использовать библиотеку `~/Documents/ScratchJR`. Файл приложения и проекты хранятся отдельно.

## Возможности выпуска

В Windows .4 добавлен запуск с пустой библиотекой по явному выбору пользователя, если при первом переносе старая база ScratchJr не читается.

Сохранены изменения .3: приложение переименовано в ScratchJGET. Исходные Тик, Так и Ток, их миниатюры и примеры восстановлены вместо роботов. Скрытые идентификаторы Cat/Cat2 отображают кота; Cat2 использует ту же позу, что Cat. [Происхождение ресурсов](CHARACTER-RESTORATION.md).

Сохранены возможности предыдущих сборок:

**Клавиатура.** В жёлтой категории появился блок «Нажата клавиша». Можно выбрать одну из четырёх стрелок, «Пробел» или любую из 33 русских букв, включая Ё. При английской раскладке буквы определяются по русской маркировке физических клавиш. Во время ввода текста и рисования клавиатурные цепочки приостановлены. Выбор сохраняется в проекте.

**Касание выбранного персонажа.** Отдельный жёлтый стартовый блок реагирует на конкретного персонажа с текущей страницы. Цель выбирается по миниатюре и имени. Переименование не сбрасывает выбор; после удаления цели нужно выбрать новую. Скрытые персонажи и персонажи с других страниц не вызывают событие. Обычный блок столкновения с любым персонажем сохранён.

**Библиотека звуков.** Добавлены 43 звука: 15 животных, 9 природы, 6 музыкальных, 8 эффектов и 5 звуков техники. Вместе с прежним `pop` доступны 44 звука. В зелёной категории нажмите «+ Звук». Кнопка ▶ проигрывает пример, нажатие на название добавляет звук в проект. Ранее выбранные звуки остаются отдельными блоками зелёной панели и сохраняются даже без использования в сценарии. Подборка общая для персонажей и страниц проекта; длинный список перелистывается стрелками. Каталог работает без интернета. Записи с микрофона остаются отдельными.

**Рисование и сохранение.** Включены исправления зависания при обработке линии, ограничение истории отмены рисунков, повтор сохранения при ошибке и сохранение проекта перед закрытием окна. На Windows рисунки и другие медиа хранятся рядом с базой в папке `media`.

**Отклик интерфейса.** Убраны две искусственные блокировки по 1000 мс: после отмены библиотеки персонажей/фонов и после загрузки списка проектов. Задержка физического нажатия, отмеченная на Mac, в тестовом проекте не воспроизведена; устранение любой задержки не подтверждено.

## Совместимость проектов

В ScratchJGET сохранён формат прежних проектов. Новые блоки клавиатуры и выбранного касания отсутствуют в исходном ScratchJr Desktop. Для передачи проекта с новыми звуками на другой компьютер используйте **ScratchJGET 1.3.2-jget.3 или новее**: стандартный экспорт проекта не вкладывает встроенные звуки в архив.

Если требуется вернуться к старой версии, закройте все версии приложения, сохраните отдельно текущие работы и используйте прежнее приложение/установщик вместе с резервной копией библиотеки, сделанной перед обновлением. На Windows сохранённая библиотека исходного ScratchJr не содержит работ, созданных после перехода на Classroom или ScratchJGET.

Перед первым занятием откройте прежний проект, создайте тестовый рисунок, добавьте движение и звук, закройте программу и откройте проект снова. Это проверяет работу именно на компьютере ученика; результаты на других устройствах не заменяют такую проверку.

## Проверки и ограничения

Для Windows .4 пройдены 15 локальных программных регрессий и проверки упаковки. [Отчёт локальной проверки](release-checks/2026-11-17/legacy-library-recovery/README.md). Проверка на школьных Windows-компьютерах, сообщивших об ошибке, ещё не выполнена.

На Mac для выпуска .3 выполнены нативные проверки переименованной сборки, открытия тестового проекта из предыдущей версии и сохранения рисунка, сценариев, «Пробела» и подборки звуков. Использовалась отдельная временная библиотека; пользовательские проекты не открывались. [Отчёт Mac](release-checks/2026-11-16/scratchjget-rename.md). Синтетические события в этих проверках не измеряют физическое касание тачпада. Испытания на одном компьютере не заменяют пробный запуск на школьных устройствах.
