## Проверка на Windows

[GitHub Actions](https://github.com/user116RUS/J-GET-Junior/actions/runs/44089485838) завершилась успешно на Windows Server 2022 AMD64 за 2 минуты 7 секунд.

- Установка поверх .1: обновлены программа и ярлыки; папка проектов сохранена.
- Все 15 программных регрессий прошли.
- Настоящее упакованное приложение запущено с искусственно нечитаемой старой базой. При отмене редактор не открылся и новая база не появилась.
- При выборе пустой библиотеки открылась сохранённая база без проектов; исходная база, журнал и медиа остались неизменными по SHA-256.
- Создан и сохранён тестовый проект с рисунком, сценариями и звуками. После повторной установки и запуска проект восстановился, повторного запроса о старой библиотеке не было.
- Удаление программы сохранило библиотеку.

Ответы на диалог в тестовой копии подавались автоматически. Это проверка приложения на Windows CI, а не физической работы ребёнка за школьным компьютером. Копия базы с фотографии не получена; старые пользовательские проекты не восстанавливались.
