# Проверка выпуска ScratchJGET 1.3.2-jget.3

16 ноября 2026 года. Подготовлены Mac Intel ZIP (Apple Silicon через Rosetta) и установщик Windows x64. Приложения и публичные файлы не содержат QA-вставок или пользовательской библиотеки.

## Проверки

Mac: нативное открытие копии тестового проекта, сохранённого предыдущей локальной версией, восстановило рисунок, сценарии, «Пробел» и шесть выбранных звуков. Имя приложения, страницы и окна — ScratchJGET. Предыдущие подробные результаты находятся в соседних `scratchjget-native-reopen.json` и `scratchjget-bundles.json`. Финальная упаковка обновляла документацию; исходники приложения не менялись. ZIP распакован, 9020 файлов и 19 символьных ссылок совпали с приложением; права исполнения сохранились.

Windows: [GitHub Actions 43764834036](https://github.com/user116RUS/J-GET-Junior/actions/runs/43764834036), исходный коммит `f366b4ae10936d910403232d1cba91d6703e67ff`, результат success. Пройдено 13 исходных регрессионных программ. Установлен опубликованный выпуск .1, затем новый .3; старый EXE и ярлыки удалены, новые ярлыки указывают на ScratchJGET.exe, сведения реестра верны. Контрольный файл прежнего каталога проектов не изменился.

Нативная Windows-проверка создала отдельный тестовый проект, сохранила рисунок, сценарии и выбранные звуки при штатном закрытии окна, переустановила приложение и успешно открыла проект снова. Проверены 43 аудиодекодирования и событие окончания воспроизведения. Повторная установка и удаление приложения сохранили контрольные суммы тестовой базы и контрольного файла штатного каталога проектов; исполняемый файл, ярлыки и запись удаления исчезли.

Проверенный установщик имеет SHA-256 `9363986846eb2e2ab13985d5165885715929f9a298cae5d59d1e591707cb5020`; он совпадает с загруженным GitHub-файлом. Все 8969 файлов payload установщика сопоставлены с portable ZIP и сборочной папкой. SHA-256 обеих публичных сборок указан в `SHA256SUMS.txt`; сервер GitHub подтвердил те же значения.

## Пределы

Windows-прогон выполнялся на GitHub runner Windows Server 2022 с `--disable-gpu --mute-audio`: это не проверка физической слышимости, тачпада, фокуса или школьного ноутбука. Самостоятельное открытие проекта, созданного именно в .1, в Windows не проверялось; проверены обновление установленного приложения и сохранность контрольного файла, а затем сохранение/повторное открытие проекта .3. Секундная задержка пользователя на Mac не воспроизведена. Старый выпуск .1 сохранён для возврата вместе с резервной копией библиотеки.
