# ScratchJGET — переименование, 1.3.2-jget.3

По запросу пользователя отображаемое имя изменено с J-GET Junior на ScratchJGET. Обновлены заголовки окон/страниц, переводы, изображения с названием, имя Mac-приложения и его helper-процессов. Настройки упаковки Windows, имя будущего EXE и ярлыков также приведены к ScratchJGET; новый Windows-установщик не собирался и не публиковался.

Сохранены внутреннее имя npm-пакета, bundle IDs, пути библиотеки проектов, Windows install/registry IDs и адрес GitHub-репозитория. Ранее выпущенные архивы сохранены под прежними именами. Текущая Mac-сборка — `ScratchJGET-1.3.2-jget.3-mac-Intel.zip`.

Проверки: весь производственный кеш и 859 исходных ресурсов совпадают с исходниками; переименованные главный и helper executable/bundle/plist согласованы. Нативное открытие копии тестового проекта, сохранённого версией .2, прошло 20 проверок: приложение, окно и документ называются ScratchJGET; восстановились рисунок, сценарии, «Пробел», шесть звуков и их палитра; все 43 аудиофайла декодировались. Редактор визуально проверен по снимку. Использовалась отдельная временная библиотека; пользовательские проекты не открывались.

Архив распакован и побайтно сопоставлен с приложением, включая символьные ссылки и права исполнения. Отчёты и снимок находятся рядом с этим файлом с префиксом `scratchjget-`. Проверки 13 программ из предыдущего изменения не повторялись: данное изменение затрагивает название и упаковку.
