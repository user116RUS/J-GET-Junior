Истории, игры
и первые программы.

Собирайте команды из блоков, рисуйте персонажей и оживляйте свои идеи. J-GET Junior работает без интернета.

Windows

64-разрядная система · установщик EXE

Скачать для Windows

Закройте приложение, запустите установщик и следуйте подсказкам. Открывайте программу через ярлык «J-GET Junior».

Mac

Intel · Apple Silicon через Rosetta

Скачать для Mac

Распакуйте ZIP и перенесите J-GET Junior.app в папку «Программы». На Mac с Apple Silicon требуется Rosetta.

Версия 1.3.2-jget.1 Описание выпуска и контрольные суммы

Больше возможностей для игр

  • Управляйте персонажами стрелками и русскими буквами.
  • Запускайте команды при касании выбранного персонажа.
  • Выбирайте звуки животных, природы, музыки и техники из встроенной библиотеки.

Перед установкой

Закройте предыдущую версию и сохраните резервную копию проектов. J-GET Junior использует прежние папки библиотеки.

Сборки не подписаны сертификатом издателя. При первом запуске Windows или macOS могут показать предупреждение.

Установка, обновление и совместимость проектов
