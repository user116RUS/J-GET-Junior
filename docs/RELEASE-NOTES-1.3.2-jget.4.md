# ScratchJGET 1.3.2-jget.4 для Windows

17 ноября 2026 года. [Скачать установщик Windows x64](https://github.com/user116RUS/J-GET-Junior/releases/download/v1.3.2-jget.4/ScratchJGET-Setup.exe) · [Страница релиза и контрольные суммы](https://github.com/user116RUS/J-GET-Junior/releases/tag/v1.3.2-jget.4).

Обновление относится к Windows. Для Mac остаётся доступен выпуск [1.3.2-jget.3](https://github.com/user116RUS/J-GET-Junior/releases/tag/v1.3.2-jget.3).

## Ошибка первого запуска

В прежнем выпуске на части компьютеров Windows первый запуск останавливался при чтении старой библиотеки из `Документы\ScratchJR` с ошибкой `file is encrypted or is not a database`. Этот текст сам по себе не доказывает, что файл зашифрован: для установления причины нужна проверка копии конкретной базы.

Если новой библиотеки ещё нет и старая база не читается, версия .4 предлагает пользователю явно выбрать «Начать с пустой библиотекой». Исходные файлы остаются на месте; новая библиотека создаётся отдельно в `%LOCALAPPDATA%\ScratchJr-Classroom\Projects`. Если старые проекты нужны сейчас, можно отменить запуск и сохранить исходную папку для проверки.

Этот вариант позволяет начать новые работы. Он **не восстанавливает старые проекты** и не подтверждает их сохранность внутри нечитаемого файла. Уже существующая рабочая библиотека не заменяется пустой из-за ошибки чтения старой базы.

## Установка

Закройте ScratchJGET, J-GET Junior и ScratchJr. Сохраните предыдущий установщик и копии всей папки `Документы\ScratchJR`, а также `%LOCALAPPDATA%\ScratchJr-Classroom\Projects` вместе с `media`, если она уже существует. Скачайте и запустите `ScratchJGET-Setup.exe`, затем откройте ярлык ScratchJGET.

В опубликованном .3 можно временно пропустить перенос, если новой библиотеки ещё нет и старые проекты сейчас не нужны: при закрытых приложениях переименуйте фактическую папку `Документы\ScratchJR` в `ScratchJR-резерв` (или другое свободное имя) и запустите ScratchJGET. Сохраните папку целиком. Новая библиотека будет пустой, а старые работы останутся отдельно. Рабочую папку `Projects` в `LOCALAPPDATA` переименовывать или удалять не нужно.

## Проверки и ограничения

Пройдены 15 локальных программных регрессий и проверки содержимого установщика и производственного кеша. [Подробный отчёт локальной проверки](release-checks/2026-11-17/legacy-library-recovery/README.md).

Копия проблемной базы не получена. Проверка исправления на компьютерах, сообщивших об ошибке, ещё не выполнена; восстановленных пользовательских проектов нет. Проверки на синтетических данных и упаковки не заменяют запуск на этих устройствах.

После установки создайте тестовый проект с рисунком, закройте приложение и откройте проект снова. Если выбрана пустая библиотека, отсутствие старых работ в ней ожидаемо. Подробная инструкция находится в [памятке для Windows](Windows-класс.txt).
